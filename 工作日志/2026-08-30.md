## 踩坑记录

1. **CS1061 ModelImporter 属性不存在**：Unity 2022.3 LTS 没有 normalMode/tangentImportMode/skinQuality/compression/motionType/keepOriginalXXX/materialPropertyAccess 等 2023+ 新属性。解决：只用官方文档确认的属性，宁可少设不瞎设。

2. **CS0117 ModelImporterAnimationType.Humanoid 不存在**：2022.3 枚举值是 `Human` 不是 `Humanoid`。

3. **CS0200 referencedClips 只读不能赋值**：跳过这行。

4. **GLB 文件 Unity 2022.3 原生不支持**：.meta 里只有 DefaultImporter 占位。解决：Validator 和 ImportProcessor 都跳过 .glb，只用 .fbx。以后要用 GLB 需装 UnityGLTF 插件。

5. **Validator 读 ModelImporter.animationType 和 .meta 文件不同步**：Unity 缓存问题。解决：Validator 直接用 File.ReadLines 读 .meta 里的 `animationType: X` 数字（None=0, Legacy=1, Human=2, Generic=3）。

6. **PlayerController 硬依赖导致 CS0246**：CheckDefeatCondition 里 GetComponent<BattleBall.Battle.PlayerController>() 在 PlayerController 还没迁时编译报错。解决：改成 activeInHierarchy 基础检查，解耦。

7. **Player 模型 Avatar isHuman=false**：Q版大头模型骨骼名不匹配 Unity Humanoid 映射表。解决：放弃 Humanoid，改用 Generic Rig + Generic Avatar（自动 Create From This Model 100% 有效）。

8. **Unity Console Warning 自动合并折叠**：循环 Debug.LogWarning 多条相同堆栈会被 Unity 合并成一行。解决：用 StringBuilder 拼成一大段 + 弹窗直接列前20条。

9. **TagManager.asset Parser Failure**：PowerShell Set-Content -Encoding UTF8 偷偷加 BOM 头，Unity YAML 要求纯 UTF-8 无 BOM。解决：用 new UTF8Encoding(false) 明确写无 BOM。

10. **CS0104 UnityEngine.Object 二义性**：UnityEngine.Object 和 System.Object 同名冲突。解决：using Object = UnityEngine.Object;

# 积分预算强制控制

## 触发条件

当执行以下任何操作时，**必须触发本技能**：
- MCP 工具调用（Blender MCP、Godot MCP）
- 任何消耗积分的代码执行
- 批量任务操作
- 用户要求"继续执行"或"开始任务"

## 三条强制规则

### 规则 1：事前报预算

在执行任何消耗积分的操作**之前**，必须：

1. 明确列出本步骤的预计积分消耗
2. 说明操作内容和目的
3. **等待用户明确确认**后才能执行

```
示例：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 本步预算报告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
操作：在 Blender 创建场地边框几何体
预计消耗：~300 积分
是否执行？（是/否）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 规则 2：事后报消耗

每完成一个操作步骤**之后**，必须：

1. 报告实际消耗的积分（估算值）
2. 累计总消耗
3. 更新剩余预算

```
示例：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ 完成报告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
操作：创建场地边框
实际消耗：~280 积分（预算300）
累计消耗：280 / 5000
剩余预算：4720
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 规则 3：80% 硬停规则

当累计消耗达到**总预算的 80%** 时，必须：

1. **立即停止所有操作**
2. 强制汇报当前状态
3. 请求用户决定：继续/停止/调整预算

```
示例：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⛔ 预算告警 - 达到 80% 阈值
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
总预算：5000 积分
累计消耗：4050 (81%)
剩余：950

⚠️ 已达到硬停点，强制暂停！

请选择：
1. 停止所有工作
2. 调整预算上限
3. 继续剩余任务（谨慎）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 执行流程模板

```
Step 1: 报预算 → 等待用户确认
Step 2: 执行操作
Step 3: 报消耗 → 更新累计
Step 4: 检查是否达80% → 是则强制暂停
Step 5: 循环直到任务完成
```

## 累计消耗追踪表

每轮对话中必须维护以下表格：

| 步骤 | 操作 | 预算 | 实际 | 累计 | 状态 |
|------|------|------|------|------|------|
| 1 | - | - | - | 0 | 待执行 |
| 2 | - | - | - | - | - |

## 违规处理

如果违反以上任何规则：
- 用户可以随时叫停
- 之前的消耗依然计入总额
- 必须重新获得用户信任才能继续

## 核心原则

**宁可慢，不可乱花。宁可停，不可超标。**
